📋 Present-tense forms

SubjectCONOCERSABER
yoconozcosé
túconocessabes
él / ella / ustedconocesabe
nosotros / nosotrasconocemossabemos
vosotros / vosotrasconocéissabéis
ellos / ellas / ustedesconocensaben

The yo forms are irregular: conocer → conozco; saber → sé. Other present-tense forms follow regular -er endings.

For many -cer/-cir verbs with a preceding vowel, yo changes c → zc: agradecer → agradezco, parecer → parezco, aparecer → aparezco, ofrecer → ofrezco, producir → produzco, traducir → traduzco.
